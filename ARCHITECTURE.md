# Architecture

Use a private GitHub repository for source control and GitHub Actions for two daily polling runs. Use SQLite for local reproducibility and PostgreSQL in an isolated Supabase project for hosted persistence. Deploy the dashboard as a separate Netlify site. Supabase row-level policies restrict reads to an explicit operator allowlist and restrict pipeline edits to the signed-in operator’s rows. The browser receives only the Supabase publishable key. The monitor’s database connection string and email credentials belong in GitHub Actions secrets.

The scheduler uses America/New_York directly, with polls at 4:15 a.m. and 4:15 p.m. and the report scheduled at 7:00 a.m. Eastern. GitHub documents that scheduled events can be delayed or dropped under load. Measure actual completion and report receipt during validation. [GitHub schedule behavior](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule)

ATS readers resolve an inventory and its pagination before passing postings through deterministic matching. The engine fetches details for likely and ambiguous leadership titles, records unresolved evaluations, and persists the resulting employer transaction with vacancy history and alert queue entries. A failed inventory leaves vacancy counts unknown and preserves existing statuses. A complete inventory can show that a listing was removed. Explicit direct source evidence is required for a filled status.

The initial budget target is $0 in incremental subscription charges within free allowances. GitHub Free includes 2,000 hosted minutes per month. Three scheduled runs per day imply about 20 minutes of average compute per run at that limit. Supabase Free has 500 MB of database storage and can pause after a week of inactivity. Netlify Free credit accounts have a hard limit of 300 monthly credits. Resend Free has daily and monthly quotas. Leave AI calls disabled during the initial calibration. Records keep missing values empty and the dashboard shows them as unknown. The app stores monitoring data, vacancies, evidence events, and delivery state in separate tables. Additional intelligence collectors can use the same evidence approach and define their own source types and review stages. They are deferred until direct employer coverage improves.
